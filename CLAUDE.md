# Site statique publié avec GitHub Pages

Ce dossier est un dépôt Git public. Tout ce qu'il contient est publié sur
https://haithemoo.github.io/mon-site/ après chaque push sur la branche `main`.

## Règles de travail

- Le site est statique (HTML, CSS, JS, Markdown) : pas de backend ni de framework.
- Ne jamais ajouter de secrets (clés API, mots de passe, fichiers `.env`) : le dépôt est public.
- À la fin de chaque tâche : `git add .`, commit avec un message clair en français, puis `git push`.
- Avant de pousser, vérifier avec `git status` qu'aucun fichier privé n'est inclus.
- Répondre en français.
